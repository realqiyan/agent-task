# 本机 Web 控制台

控制台与 MCP 共用 HTTP 服务，只监听 `127.0.0.1`。访问 `http://127.0.0.1:<port>/admin/`，不要改用 LAN 地址、反向代理或公网转发。

全部管理操作也可通过 [CLI](cli.md) 完成，两端使用同一管理 API 和底层服务。

## 启用与连接

新安装由 `agent-task setup`（[实现](../scripts/setup.mjs)）在当前 `dataDir/environment.json` 中生成独立的 `AGENT_TASK_ADMIN_TOKEN`。用本地编辑器读取该字段并在连接表单输入；它不是 MCP token，不能放进 URL、命令参数、截图或日志。

已有文件不会由 setup 补写或覆盖。缺少管理员令牌时，管理接口关闭。需要启用时先停服，用本地密码管理器生成独立随机令牌，离线加入该字段；令牌约束见 [environment.ts](../src/configuration/environment.ts)。不要复用服务或模型密钥。

启动入口，见[部署说明](deployment.md)。配置和环境文件须属于当前用户、权限为 `0600`，所在目录须为规范绝对路径、权限为 `0700`，不接受符号链接。环境文件仅在运行进程启动时加载。文件格式见 [environment.ts](../src/configuration/environment.ts)。

令牌仅保留在页面内存中；退出、离开或刷新后重新连接。不设置 Cookie，不写浏览器持久存储。配置和密钥文件仍是本地明文，须按凭据保护；此方案不隔离同一 OS 用户的其他进程或恶意浏览器扩展。

## 操作范围

- 任务列表、固定 DAG、运行历史、节点进度、已接受交付、错误和问题只读。触发计划结束不等于运行成功，原始输出不等于交付。
- 任务写操作仅复用 `task_update`，暂停、恢复或取消未来触发。不停止当前运行，不补跑错过的触发，不回答问题或修改 DAG。已有不确定外部结果的任务拒绝恢复未来触发；当前不提供人工核对后强制恢复能力。
- 协调模型是常规配置入口。数据目录、监听端口、MCP token 环境变量名和执行端启停位于高级设置，下次启动生效。修改 token 变量名保留令牌值，不在页面回显。
- 执行端页面显示本机路径、准备结果和错误，提供重新检测、显式适配器升级及自定义本机 stdio ACP 注册/注销。注册使用管理员权限，立即生效且不重启；范围与风险见 [CLI 接入说明](cli.md#自定义本机-acp-接入)。就绪不代表原生认证或工具权限已经验收；安装、更新及原生环境边界见[部署说明](deployment.md#执行端发现与准备)。

页面与接口入口见 [web.ts](../src/protocol/http/web.ts)、[页面模块](../src/web/)，任务契约见 [task-contract.ts](../src/protocol/task-contract.ts)。提供受管理员认证保护的重启入口；没有通用 MCP 代理、文件浏览器或下载接口。固定结果目录不授予整个 dataDir 的读取能力。

## 保存与重启

1. 密钥只显示是否设置，原值不回显。不提交即保留；替换和删除必须明确操作。先保存新密钥，再保存引用它的配置。新凭据命名和受保护变量见 [settings.ts](../src/configuration/settings.ts)。
2. 配置先校验并预览影响，再确认保存。校验不调用模型或启动 ACP，不能证明认证、原生权限或实际执行成功。禁用执行端时显示受影响任务，不自动改派。
3. 配置与密钥分别原子替换，不是跨文件事务。更换模型端点须使用新的凭据引用，避免中途重启将新密钥交给旧端点。旧凭据不自动清理。
4. 启动配置和凭据保存不热更新；自定义执行端注册/注销不属于此流程。检查活动运行及待回答运行后，点击“重启并检查可用性”或执行 `agent-task restart`。目录切换、原生环境来源及故障处理见[部署说明](deployment.md)。
5. 只有新进程通过认证健康检查才显示成功。页面清除令牌并给出新地址，重新连接后核对运行配置。请求未确认时先用 CLI status 核查，不删除历史、自动回滚或重放执行来修复。

待回答运行也可能持有 ACP 会话，重启不保证无损续接。执行端未就绪、被禁用或本机路径与任务快照不一致时，旧任务的派发会被拒绝；页面不改写快照、DAG 或执行端指派。需要新任务时由 MCP 调用方处理。

Web 与 CLI 的旧编辑都会被拒绝，不做自动合并。离线编辑配置须先停服。校验与保存职责见 [settings.ts](../src/configuration/settings.ts)、[配置影响预览](../src/configuration/management.ts)、[settings-contract.ts](../src/protocol/settings-contract.ts)、[配置文件适配](../src/configuration/files.ts)。

## 安全与验收

管理接口使用独立 Bearer 认证、严格 Host/Origin 检查及 JSON 写请求，不开放 CORS；MCP 不接受控制台令牌或浏览器 Origin。页面以纯文本展示不可信内容，不渲染模型 HTML 或 Markdown，不自动加载外链。密钥不进入 API 读取结果或服务日志，Agent 输出仍可能敏感。

证据与未验证边界统一见[验证说明](validation.md#控制台验证)。
