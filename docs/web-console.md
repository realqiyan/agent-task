# 本机 Web 控制台

控制台与 MCP 共用 HTTP 服务，只监听 `127.0.0.1`。访问 `http://127.0.0.1:<port>/admin/`，不要改用 LAN 地址、反向代理或公网转发。

## 启用与连接

新安装由 `agent-task setup`（[实现](../scripts/setup.mjs)）在私有 `environment.json` 中生成独立的 `AGENT_TASK_ADMIN_TOKEN`。用本地编辑器读取该字段并在连接表单输入；它不是 MCP token，不能放进 URL、命令参数、截图或日志。

已有文件不会由 setup 补写或覆盖。缺少管理员令牌时，管理接口关闭。需要启用时先停服，用本地密码管理器生成独立随机令牌，离线加入该字段；令牌约束见 [main.ts](../src/main.ts)。不要复用服务或模型密钥。

托管服务已绑定配置和环境文件。手动部署使用：

```bash
agent-task start --config /absolute/private/config.json \
  --environment /absolute/private/environment.json
```

两个文件须属于当前用户、权限为 `0600`，所在目录须为规范绝对路径、权限为 `0700`，不接受符号链接。环境文件仅在进程启动时加载；显式文件模式不回退到 shell 凭据。文件格式和基础环境来源见 [environment.ts](../src/environment.ts)、[install-lib.mjs](../scripts/install-lib.mjs)。

令牌仅保留在页面内存中；退出、离开或刷新后重新连接。不设置 Cookie，不写浏览器持久存储。配置和密钥文件仍是本地明文，须按凭据保护；此方案不隔离同一 OS 用户的其他进程或恶意浏览器扩展。

## 操作范围

- 任务列表、固定 DAG、运行历史、节点进度、已接受交付、错误和问题只读。触发计划结束不等于运行成功，原始输出不等于交付。
- 任务写操作仅复用 `task_update`，暂停、恢复或取消未来触发。不停止当前运行，不补跑错过的触发，不回答问题或修改 DAG。
- 注册信息、ACP 权限和协调模型配置可编辑；数据目录、监听端口和服务认证配置只读。执行端原生认证及权限继续使用其官方工具。

页面与接口入口见 [web.ts](../src/web.ts)、[页面模块](../src/web/)，任务契约见 [task-contract.ts](../src/task-contract.ts)。没有通用 MCP 代理、文件浏览器或重启接口。

## 保存与重启

1. 密钥只显示是否设置，原值不回显。不提交即保留；替换和删除必须明确操作。先保存新密钥，再保存引用它的配置。新凭据命名和受保护变量见 [settings.ts](../src/settings.ts)。
2. 配置先校验并预览影响，再确认保存。校验不调用模型或启动 ACP，不能证明认证、原生权限或实际执行成功。修改执行端字段后，页面要求重新明确批准无人值守执行。
3. 配置与密钥分别原子替换，不是跨文件事务。更换模型端点须使用新的凭据引用，避免中途重启将新密钥交给旧端点。旧凭据不自动清理。
4. 保存不更新当前进程的配置、权限或环境。检查活动运行及待回答运行后，按[后台管理](deployment.md#后台管理)手动重启；故障后的自动拉起也会读取已保存值。
5. 重启后重新连接并核对运行配置。启动失败须从终端修正私有文件；提交结果不确定时停止继续保存并停服核查。不删除历史、自动回滚或重放执行来修复。

待回答运行也可能持有 ACP 会话，重启不保证无损续接。执行端注册信息与任务快照不一致时，旧任务的派发会被拒绝；页面显示受影响任务，但不改写快照、DAG 或执行端指派。需要新任务时由 MCP 调用方处理。

多个页面的旧编辑会被拒绝，不做自动合并。离线编辑配置须先停服。校验与保存职责见 [settings.ts](../src/settings.ts)、[settings-contract.ts](../src/settings-contract.ts)、[private-files.ts](../src/private-files.ts)。

## 安全与验收

管理接口使用独立 Bearer 认证、严格 Host/Origin 检查及 JSON 写请求，不开放 CORS；MCP 不接受控制台令牌或浏览器 Origin。页面以纯文本展示不可信内容，不渲染模型 HTML 或 Markdown，不自动加载外链。密钥不进入 API 读取结果或服务日志，Agent 输出仍可能敏感。

证据与未验证边界统一见[验证说明](validation.md#控制台验证)。
